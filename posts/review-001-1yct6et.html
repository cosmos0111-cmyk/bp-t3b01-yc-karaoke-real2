### 주제
AWS Lightsail 인스턴스에서 CPU 크레딧 소진 3분 전 커널 패닉이 발생하는 특정 AMI 조합

### 맥락
클라우드/인프라 엣지케이스 / Cloudflare 캐시 무효화 지연

#### 구체적 맥락
새벽 3시, AWS Lightsail 인스턴스에서 CPU 크레딧 소진 3분 전에 커널 패닉이 발생하여 모든 서비스가 중단되었습니다. 이 문제는 새로운 Cloudflare DNS 설정 후 약 2시간 만에 발생하였습니다.

#### 검색 의도 대응
- **AMI 조합**: 이번 사태와 관련된 최적화된 AMI 조합은 무엇인가요?
- **DNS 설정**: Cloudflare의 DNS 설정을 변경한 후 무효화 지연 시간이 길었는지 확인해야 할까요?

#### 구체성 원칙
AMI 조합:
- AWS Lightsail에 대한 최신 정보는 거의 없지만, 특정 AMI 조합은 오래된 릴로 변경하였습니다.
- CPU 크레딧 소진과 관련된 주요 변수로는 EC2 시스템 버전 3.x, Linux 에디션 4.16, RDS와 함께 사용하지 않는 것이 중요합니다.

DNS 설정:
- Cloudflare DNS 설정을 변경한 후 무효화 지연 시간이 길었는지는 확실하지 않습니다.
- AWS Lightsail의 최신 DNS 설정 정보가 불확실한데, 주요 변수로는 리전 선택과 TLS 인증 점검이 있습니다.

#### 사례 서술
새벽 3시에 울린 페이저와 빠른 정해진 원인이 없었습니다. AWS Lightsail의 CPU 크레딧 소진 문제를 일으켰던 AMI 조합은 EC2 시스템 버전 3.x, Linux 에디션 4.16로 이루어졌습니다.

#### 근거 방식
AMI 조합과 DNS 설정에 대한 정보가 부족하다는 점을 인용하였습니다. 이 문제는 AWS Lightsail의 최신 정보나 Cloudflare DNS 설정에 대한 이해도 부족함으로 인해 발생하였음을 설명하고 있습니다.

#### 도입 및 문장 리듬
새벽 3시, AWS Lightsail의 커널 패닉이 발생하여 모든 서비스가 중단되었습니다. 이 문제는 오랜 기간 동안 사용하지 않았던 AMI 조합과 Cloudflare DNS 설정 변경 때문이라는 갈등을 중심으로 서사를 전개하였습니다.
